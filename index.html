Learning Journey

I entered this program with some Python background from a college course, but I was completely new to web development. Throughout the program, I built a foundation in HTML and CSS to structure and style web pages, and I was introduced to JavaScript to make them interactive. My biggest learning experience came from developing a community app called "Friend Finder," where my team and I used HTML and CSS for the user interface and JavaScript for the backend to power a live chat feature. Building this wasn't easy, we had a unexpected error when our live chat initially only worked locally on a single device. To overcoming this challenge required us to research and integrate APIs, debugging them so the chat could successfully send messages across different devices, which ultimately taught me exactly what it takes to build a fully connected application.
